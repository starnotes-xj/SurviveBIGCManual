# 班级课表

这里整理了信息工程学院各班级的课表文件，方便提前查看上课时间和地点。

!!! warning "使用说明"
    用户提供的课表目录实际包含的是旧式 `.xls` 文件，而不是 `.xlsx` 文件。文件已按原格式放入项目，下载后可使用 Excel 或 WPS 打开。课表可能会因调课、分班或学期变化而更新，最终安排请以教务系统和任课老师通知为准。
