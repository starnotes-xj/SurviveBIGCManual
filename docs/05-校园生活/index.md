# 校园生活

来北京读书，这些事情早点办早省心。

## 银行卡

银行卡按实际需求办理，不需要为了“凑够两张”而办理：

- **北京银行卡**（必须办）→ [办理指南](银行卡办理/北京银行卡.md)
  学校奖学金、饭补（每月 25 号左右）均通过北京银行发放，不办就收不到钱。
- **工商银行 Visa 卡**（完全自愿）→ [办理指南](银行卡办理/工商银行Visa卡.md)
  仅在有境外支付等实际需求时考虑办理。这是 **0 额度信用卡**，不能透支，使用前需要先存入自己的资金，使用方式更接近储蓄卡；是否申请不影响在校学习或学校相关事务。
