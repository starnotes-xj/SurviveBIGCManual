# 校园生活

来北京读书，这些事情早点办早省心。

## 银行卡

在校期间需要至少两张卡：

- **北京银行卡**（必须办）→ [办理指南](银行卡办理/北京银行卡.md)
  学校奖学金、饭补（每月 25 号左右）均通过北京银行发放，不办就收不到钱。
- **工商银行 Visa 卡** → [办理指南](银行卡办理/工商银行Visa卡.md)
  用于订阅 ChatGPT/Claude 等境外服务，有需求再办。
