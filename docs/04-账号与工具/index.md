# 账号与工具

这些是信息安全学习的基础设施，越早配好越省事。

## 推荐配置顺序

```
GitHub → JetBrains → Google账号 → Notion / 教育邮箱 / Claude Code；网络代理工具按实际需求配置
```

网络代理工具并非所有场景都需要；如确有需求，应在遵守法律法规、学校或单位网络规定及服务条款的前提下配置。学信网验证报告和教育邮箱（本校教育邮箱申请麻烦）可用于申请部分免费工具。
