## 用途 { #purpose }

这套 Skill 整理了浏览器内 VNC 演练的操作经验，目标是帮助参与者在**明确授权的隔离演练或 CTF 靶场**中，按任务范围收集证据、核验结论并记录处置过程。它面向平台明确提供的练习靶机，不适用于生产系统、公共网络主机或未授权设备。

适合用来梳理：

- 浏览器 VNC 会话中的协作和状态记录；
- 截图、日志、文件及网络取证材料的来源与交叉核对；
- 提交前的人工复核、重复提交检查和过程留档；
- 演练结束后的问题复盘与文档整理。

## 建议工作顺序 { #workflow }

1. **确认范围**：核对主办方授权、演练时间、指定平台和靶机清单；有任何一项不明确时，先暂停操作并向负责人确认。
2. **保全证据**：只使用演练规则允许的访问方式，保留原始截图、日志或文件及其时间信息，不用猜测补齐缺失事实。
3. **交叉核验**：关键结论尽量由两项独立证据支持，并区分直接观察、推断和仍待确认的内容。
4. **人工复核**：由参与者核对题目、靶机、答案格式和当前任务状态；只在规则允许时提交，并检查是否已处理，避免重复操作。
5. **整理记录**：归档必要的证据索引和处置记录；移除密码、会话令牌及个人信息后，再整理可分享的复盘材料。

## 安全边界 { #safety }

- 每次使用都需要针对该场演练的明确授权；授权只覆盖主办方列出的平台、靶机、时间段和动作。
- 不把方法扩展到第三方或生产环境，不尝试绕过访问控制，也不关闭安全防护。
- 不在代码仓库、公开文档、截图或聊天记录中保存靶机凭据、平台令牌和个人信息。
- 如果画面、目标或操作状态与演练说明不符，或发现其他参与者正在控制同一会话，应立即停止并联系演练负责人。

## 运行环境概览 { #environment }

原始整合包面向 Windows，使用 Node.js 22 或更新版本及 PowerShell 5.1；浏览器自动化路线还需要 Chromium 系浏览器。实际使用时应以演练平台规则和组织者提供的环境要求为准。
